# License locations

- MWM: root `LICENSE`.
- Waydroid graphics payload: license texts in this directory; component origins and license identifiers are recorded in `packaging/payload/manifests/graphics-stack.lock`.
- Bundled MangoApp: notices in `mwm/vendor/mangoapp/`; upstream versions, changes and build details are provided in `mwm/vendor/mangoapp/BUILD.md` inside the separate sources package.

MangoApp notices include MangoHud, ImGui, ImPlot, Meson build files, Vulkan Headers, Vulkan Utility Libraries and the BC250 register-selection reference. Identical ImGui and ImPlot copies have been consolidated. Notices inside the corresponding source archive remain intact.

Files with the same license type but different copyright holders are retained. Generic license texts do not replace component-specific notices. This index does not establish that all corresponding graphics sources have been collected.
