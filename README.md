# mirishita-waydroid

CachyOS + Waydroid 環境下で  
「アイドルマスター ミリオンライブ！ シアターデイズ (ミリシタ)」を動作・高画質化するためのプロジェクト。

## Goals

- CachyOS で Waydroid Android 11 環境を構築
- ミリシタの安定動作
- Houdini + test_libnb による ARM 互換環境
- Mesa GLES Render Scale (RTScale) による高解像度描画
- PV 視聴向けプロファイル
- 将来的に Mirishita Waydroid Manager (MWM) で統合管理

## Components

- Waydroid
- Houdini
- test_libnb
- Mesa GLES Render Scale (RTScale)

## Status

Experimental / Work in progress
