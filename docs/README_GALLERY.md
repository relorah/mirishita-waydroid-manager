2026-10-16撮影。Gamescope、16:9、Android／Gamescopeとも1920×1080、FSR OFF、Overlay OFF。RTScale x3は1280×720基準、実際のGPUターゲット3840×2160を撮影前に確認しています。配布候補のMesa SHA256は `f34d06ed52a6576dd1f558fc0c01b503f960e5933acf5be83e1e42611548a773` です。

比較用のOFF側も表示寸法1920×1080に固定してRTScale設定を解除しました。通常のGUIのOFF既定表示は720高のため、この撮影条件とは異なります。衣装・ユニット・MV画質は条件間で揃えています。カメラ・ポーズ・照明のタイミングは完全一致ではありません。FPS等のベンチマーク値は本画像から算出していません。
